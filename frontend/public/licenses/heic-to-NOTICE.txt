The library bundles libheif and its codecs. Consult the upstream source
for their respective copyright and license terms. The application's
3rdpartylicenses.txt also includes the heic-to package license.
Upstream libheif source and license information:
https://github.com/strukturag/libheif/tree/v1.23.7

To rebuild this application's library integration, install the frontend
dependencies with npm ci and run npm run build from frontend/. Replace
the heic-to dependency with a compatible modified version to rebuild
with that version. The decoder is loaded as a separate lazy chunk.
