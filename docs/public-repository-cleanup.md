# 公開版本庫資料清理與 Flyway 部署注意事項

V3 是歷史初始化 migration，含有清空資料表的指令。已套用 V3 的資料庫**不得重新執行**它；新資料庫執行 migration 後，也不會建立預設帳號，使用者應透過註冊或 OAuth 登入建立。

歷史 migration 的內容變更會改變 Flyway checksum。部署前請先備份資料庫、核對 `flyway_schema_history` 中的版本與執行狀態，並確認待部署檔案與該環境的既有 migration 歷史相容。若驗證不符，應暫停部署，由維運者依內部程序處理；不要停用 Flyway 驗證、批次 repair，或重新執行 V3。公開版本庫不保存正式環境的 checksum 數值與維運 SQL。

目前檔案已移除舊的預設帳號，不代表 Git 歷史中的舊內容已清除，也不能取代已外洩憑證的輪替。Git 歷史清理與正式帳號處理由維運者另行安排。
