# Design

## Context
現有讀取頁每次切頁與返回前景都確認雲端資料；本次保留此新鮮度規則。

## Goals / Non-Goals
改善導覽與背景刷新回饋，於角色頁閒置時預載兩個常用畫面。無短時間 API 快取、資料預抓、寫入放寬或後端變更。

## Decisions
- Angular 導覽事件控制不攔截點擊的 M3 progress bar；完成、取消、失敗及跳過均結束回饋。草稿離開選擇沿用既有 guard。
- 已載入頁面刷新時保留 DOM 與數值，顯示行內更新中提示。先前内容不得被較早的裝置副本替換，成功雲端結果才更新。正式操作仍停用至相關最新資料完成，失敗仍沿用原有清除及錯誤流程。
- Angular PreloadingStrategy 只處理標記的冒險列表／倉庫 loadComponent。角色頁啟動穩定後使用 requestIdleCallback；不支援時延後一秒。離線或省流量略過，預載失敗不影響正常導覽，也不建立元件或觸發 API／草稿。

## Risks / Trade-offs
預載增加少量背景程式碼下載，可能與點擊同時發生；由 Router 共用同一載入工作。雲端 API 等待時間仍存在，既有資料僅供閱讀，不視為本輪已確認。
