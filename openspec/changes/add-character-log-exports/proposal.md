# Proposal

## Why

玩家目前只能在網站查閱冒險，缺少可攜至遊戲桌的紙本紀錄與可自行整理的試算表。本次依使用者提供的既有紙本範本，規劃單一角色全部已儲存冒險的 PDF 與 Excel 匯出。

## What Changes

- 在角色冒險列表加入「匯出」選單，提供「紙本紀錄表（PDF）」與「Excel（.xlsx）」，兩者均匯出該角色全部紀錄，不受畫面搜尋或排序影響。
- PDF 直接使用使用者提供的原始 PDF 範本填值，完整保留原有圖案、浮水印、框線、標籤、頁首／頁尾與每頁三筆冒險配置，不重建或改版，按日期由舊到新。備註區列出獲得物品的名稱／歷史數量、休整活動描述與故事獎勵名稱，共用 11 pt、最多三行及 120 個可見字元（含標籤、標點、空白與截尾省略號）；超量直接截尾，不續頁、不延伸至其他欄位或下一筆紀錄。
- Excel 提供角色資料、冒險紀錄、獲得物品、休整活動、故事獎勵五張工作表，以一般玩家閱讀所需內容為主，不輸出內部 UUID、待補、版本、建立／更新時間及續文輔助欄等系統資訊；明細以本次冒險編號、遊玩日期及冒險名稱對應，分類值使用中文，保留可計算的數字與日期型別。超長文字僅在同列增加具原欄名的接續內容欄，不截斷全文。
- 兩種格式共用經所有權驗證、同一讀取快照的雲端資料；保留已存歷史資源、原始獲得數量、缺值及警告，不因匯出改寫資料。PDF 是紙本摘要，休整活動與其他備註內容共用容量並可截尾；完整冒險備註、休整活動、物品效果及獎勵敘述留在 Excel 與網站，不另印完整明細附頁。
- 規範下載中、失敗重試、無紀錄、離線與帳號切換狀態；不匯出草稿、帳號 Email、認證資訊或與冒險無關的倉庫清單。

## Capabilities

### New Capabilities

- `adventure-export`: 單一角色完整冒險的紙本 PDF 與 Excel 匯出、欄位對照、格式可讀性、資料完整性與下載行為。

### Modified Capabilities

無。沿用 adventure-log、inventory-provenance、state-consistency 與 local-read-cache 既有規則；匯出專屬的附加限制放於新 capability，不改寫既有編輯與查閱契約。

## Impact

- 前端：冒險列表工具列、`AdventureService` 的二進位下載、既有認證與讀取失效機制；使用 Angular Material 選單、進度與訊息，不新增匯出設定頁。
- 後端：新增受 JWT 保護的角色匯出 API、完整讀取 DTO、批次物品查詢及 PDF／XLSX 產生器；沿用 MyBatis、所有權查詢及既有 DTO／歷史警告邏輯。
- 依賴：預計後端新增 Apache PDFBox、Apache POI 與可嵌入的繁中字型資源；版本與相容性在實作時確認，前端不加入檔案產生套件。
- 資料庫：唯讀功能，不需 migration、不新增匯出紀錄表、不變更既有時間戳。
- 文件／驗證：實作時同步 SRS、使用者故事與主規格；驗證權限、並行快照、歷史／舊資料、中文長內容、分頁、Excel 型別與下載狀態。
- 範本：已檢視使用者提供的兩頁空白 PDF（630 × 810 pt、每頁三筆、132 個文字欄位）。依使用者要求直接作為固定範本，保留原有品牌圖稿與版權文字，實作時以相同內容的範本資源載入並驗證雜湊，不依賴使用者電腦絕對路徑。舊版規則文字保留原貌但不構成新增業務規則；摘要與角色資料時間性的說明放於下載介面及 PDF metadata，不改動原版頁首／頁尾。
