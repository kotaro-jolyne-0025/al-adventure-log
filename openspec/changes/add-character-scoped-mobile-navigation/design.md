## Context

角色頁共用冒險紀錄與倉庫路由。手機使用固定底部導覽，桌機沿用角色頁上方頁籤。

## Decisions

- 600 CSS px 為手機導覽斷點；角色根路由導向冒險紀錄。手機表單隱藏底部導覽。
- 手機以原生折疊控制呈現「資源總覽」，保留角色識別資訊。檢視冒險詳情及編輯冒險或物品時，由頂欄提供目前角色名稱。
- 頂欄與角色頁共用 1080px 寬度基準。安全區、文字截斷、容器與排序回歸規則見 DESIGN.md。

## Validation and rollout

以角色列表、冒險紀錄、倉庫、冒險詳情和編輯頁比較桌機、手機與斷點，涵蓋焦點可見性、清單工具列及安全區。
