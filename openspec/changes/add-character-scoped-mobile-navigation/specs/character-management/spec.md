## ADDED Requirements

### Requirement: Character scoped mobile bottom navigation

角色資料可顯示時，寬度不超過 600 CSS px 的角色頁 SHALL 提供固定底部導覽，目的地為「冒險紀錄」與「倉庫」，各有圖示、文字與目前位置狀態。桌機 SHALL 使用角色頁上方頁籤。角色列表 SHALL 維持全站頂欄，品牌入口在登入時返回角色列表。

#### Scenario: 首次進入角色

- **WHEN** 玩家從角色列表或角色根路由進入角色
- **THEN** 預設開啟冒險紀錄；直接開啟既有倉庫連結時顯示該角色的倉庫

#### Scenario: 往返角色內容

- **WHEN** 玩家在同一角色的冒險紀錄與倉庫間切換
- **THEN** 目的地反映目前路由並維持角色範圍；有手機底部導覽時，兩個清單省略重複標題及圖示，保留新增入口與庫存紀錄入口

#### Scenario: 開啟新增或編輯表單

- **WHEN** 玩家在手機開啟角色頁內的新增或編輯表單
- **THEN** 底部導覽暫時隱藏，表單提供返回及原有儲存、取消與草稿行為

### Requirement: Collapsible mobile character resources

手機角色卡 SHALL 顯示頭像、角色名稱、角色資訊與可用的編輯入口。「資源總覽」SHALL 預設收合，整列可操作，文字靠左、展開符號靠右；只切換資源內容。角色卡 SHALL 隨頁面捲動，桌機角色卡直接顯示資源。

#### Scenario: 收合或展開資源

- **WHEN** 玩家操作「資源總覽」
- **THEN** 切換等級、金幣、休整期、永久性魔法物品與靈魂幣區塊，角色識別資訊仍顯示

#### Scenario: 檢視或編輯現有資料

- **WHEN** 玩家在手機或桌機檢視冒險詳情、編輯冒險紀錄或編輯物品
- **THEN** 隱藏角色卡，頂欄品牌旁顯示已載入的當前角色名稱；長名稱可截斷且不得擋住工具列操作，返回列表時恢復角色卡

### Requirement: Navigation layout preserves existing content geometry

導覽調整 SHALL 保留冒險紀錄與倉庫已確認的搜尋、篩選、排序、卡片及新增操作排版。頂欄的共用寬度、安全區與回歸驗證遵循 DESIGN.md。

#### Scenario: 排序膠囊回歸

- **WHEN** 以相同視窗與資料比較導覽調整前後的冒險紀錄與倉庫
- **THEN** 排序膠囊維持既有寬度、對齊及右側留白；手機排序填滿可用寬度

#### Scenario: 跨斷點或鍵盤操作

- **WHEN** 玩家跨越 600／601 CSS px 斷點或以鍵盤在角色頁操作
- **THEN** 顯示對應尺寸的導覽；保留底部安全區與可見焦點，固定導覽不得遮住頁尾操作
