# 第一批 P1 UI 改善驗證

日期：2026-10-05。沿用既有 UI 風格；本批涵蓋搜尋字級、指定手機操作熱區、頭像裁切及驗證頁主題文字。

驗收：使用者於 2026-10-06 確認本批修改驗收 OK；已封存。此確認不額外推定裝置或測試範圍。

## 自動化檢查

在 `frontend/` 執行：

```sh
npm test -- --watch=false
npm run build
```

- 9 個測試檔、32 個測試通過；新增 5 個裁切回歸案例，涵蓋不同預覽尺寸的滑鼠座標換算、觸控結束／取消，以及拖曳與縮放後的 300×300 匯出。
- Production build 通過。
- `openspec validate improve-mobile-ui-ergonomics --strict` 通過。
- `openspec validate mobile-pwa --type spec --strict` 通過。

## 瀏覽器操作與量測

使用本機 Angular 開發伺服器、Chromium 與虛構測試 API；未寫入正式資料。測試 API 模擬角色、冒險、永久／消耗物品及驗證頁回應。

| 範圍 | 結果 |
|---|---|
| 320／360／390／768px 下角色、冒險、永久及消耗物品，共 16 個頁面案例 | 搜尋字級至少 16px；指定編輯、刪除、清除搜尋、返回及使用者按鈕至少 44×44px；檢查的熱區沒有重疊或水平溢出；清除搜尋可正常操作 |
| 320／360／390／1280px 頭像裁切 | 預覽寬度約 232／258／287／320px；預覽、滑桿及動作列在容器內；手機動作按鈕至少 44px 高 |
| 裁切滑鼠拖曳及單指觸控／取消 | 顯示座標按預覽比例換算到畫布；取消後停止拖曳；實際輸出 300×300，取樣像素與預覽對應位置一致 |
| 明暗主題登入、註冊、忘記密碼、失效連結及錯誤／成功，共 16 個狀態 | 量測的重要自訂文字對比均至少 4.5:1；明亮主題最低約 4.76:1，深色主題最低約 5.81:1，錯誤文字約 7.24:1 |
