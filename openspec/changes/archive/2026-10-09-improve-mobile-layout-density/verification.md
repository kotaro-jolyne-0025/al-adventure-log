# 第一批手機密度改善驗證

日期：2026-10-08。目標版本 v1.3.0；本批只完成手機字級、角色摘要與列表工具列，產品版號仍為 1.2.2，未提交或發布。

## 修改範圍

- 新規則限定不超過 600 CSS px，既有較大螢幕規則保留。
- 手機主要列表／表單標題為 16–17px，冒險卡名稱及 HUD 數字為 16px；輸入文字與既有小字維持原有規則。
- 角色摘要縮減外距；角色編輯、冒險／物品新增與編輯頁提供原生「角色資源」展開，保留五項數值。
- 冒險／倉庫新增入口與標題同行，排序獨立一列；長冒險名稱、代碼與 DM 換行。

## 手機操作與長文字

以 production build、本機 Chrome 及虛構 GET API 驗證，共 88 組：

- 320／360／390／600px，明暗主題；冒險新增／編輯、角色新增／編輯、物品新增／編輯、冒險詳情共 56 組。
- 冒險／倉庫長資料，四種寬度、明暗主題及 100%／200% 根字級共 32 組。資料含長角色名、大金幣數值、連續英文冒險名稱／代碼／DM 與品名／來源。
- 主要文字、標題與新增入口無水平裁切或重疊；新增、排序及資源展開入口高度至少 44px，文字輸入至少 16px。
- 原生資源展開支援 Enter、Space 與實際指標操作；焦點可見、五項數值完整，收合後保留備註輸入。
- 搜尋與清除、排序欄位、鍵盤切換方向與焦點、兩種新增導覽通過；新增永久物品保留 `type=PERMANENT`。
- 無 pageerror；所有資料請求皆為截取的 GET，沒有寫入正式或本機資料庫。

操作檢查使用系統後備字體，攔截遠端字體資源以隔離網路載入；200% 是根字級 16→32px 的模擬。環境的動畫影格／截圖等待曾逾時，最後操作檢查採元素邊界與實際指標點擊，不依賴穩定影格等待。未宣稱完成 iOS／Android 實機、系統字級、鍵盤或螢幕閱讀器驗收。

本機驗證程式：`output/playwright/mobile-density-focused.cjs`；結果：`output/playwright/mobile-density-check/focused-results.json`。
