# Proposal

## Why

v1.3.0 的目標為改善手機排版。使用者回報字體看起來偏大；390×844px 示範資料量測中，角色摘要高約 309px，第一筆冒險及永久物品分別從約 685px、818px 才開始。第一批以字級、摘要及列表工具列降低堆疊高度。

## What Changes

- 在不超過 600 CSS px 的手機視窗，縮小主要列表／表單標題至 16–17px，保留輸入框 16px 與既有輔助文字可讀性。
- 精簡角色摘要間距及資源卡高度，保留等級與四項資源。手機表單只先呈現角色身分，資源可由原生展開控制讀取。
- 手機冒險／倉庫標題與簡短新增按鈕同行，排序及搜尋保留原操作與可見焦點。
- 手機冒險長名稱、代碼與 DM 可換行，避免卡片裁切。
- 以桌機現有畫面作為回歸基準；版本發布與後續篩選／表單密度調整另行追蹤。

## Capabilities

### New Capabilities

無。

### Modified Capabilities

- `mobile-pwa`: 手機字級、摘要的可展開形式與列表工具列密度。

## Impact

前端共用手機樣式、character-shell 模板／樣式及冒險／倉庫新增按鈕標籤，DESIGN.md、SRS 與 OpenSpec。無 API、資料庫或依賴變更。本批不更新發布版號。
