# 摺疊與動態視窗第一階段驗證

2026-10-09，以已推送v1.4.0的`e4b2e07`為基準。完成第一階段前端調整，產品版號保持1.4.0；以下為提交前工程驗證紀錄，使用者後續已授權本機commit，尚未push、合併、發布或部署。所有API驗證使用虛構資料攔截，未操作正式資料。

## 已實作

- 角色列表／shell／角色、冒險與物品表單在所有寬度消耗左右安全區；shell下的內頁保持普通邊距，避免重複安全區。
- 確認與裁切dialog限制在四邊安全區與可視高度內，長內容捲動且操作可達。移除舊手機container額外16px padding，以修正內層100%高度溢出；保留內容與動作自身間距及觸控尺寸。
- ViewportService把未pinch zoom的visualViewport高度與offsetTop傳到CSS；可視高度<=600px時冒險表單操作回文件流。視窗事件合併為requestAnimationFrame，銷毀清理listener與CSS狀態；尺寸事件不發送業務API。
- 預覽尺寸變化不重設裁切scale／offset或300×300輸出。標記區域內控制項因尺寸隱藏時，焦點接續至同區域可見入口；仍可見的欄位焦點不變。
