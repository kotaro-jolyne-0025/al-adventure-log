# Proposal

## Why

玩家可能在查倉庫或填冒險紀錄途中展開、摺回、旋轉手機或縮小分割視窗。既有手機與桌機驗收是基礎，但尚未建立這些連續變化的操作契約；先提出適用於 Duo 與其他可調整視窗裝置的網頁設計。

## What Changes

- 第一階段沿用已驗收的單頁、卡片、頂部導覽與600／768 CSS px斷點，補全四邊安全區、短視窗與浮層的設計規則。
- 明確定義同一頁尺寸變化時的搜尋、排序、分類、表單、錯誤、焦點與裁切狀態保留；不因resize重載頁面或提交資料。
- 對展開、摺回、分割視窗、鍵盤縮小可視區建立工程驗證矩陣；模擬與實機結果分開記錄。
- Viewport Segments只作後續能力增強設計：取得可靠區域資訊才規劃避讓，不靠機種名稱、螢幕吋數或固定折痕寬度猜測。
- 初次交付為設計與實作任務，後續使用者指示繼續後進入第一階段實作；不納入先前已推送的commit，尚未指定後續發布版本。

## Capabilities

### New Capabilities

無。

### Modified Capabilities

- `mobile-pwa`：補充動態視窗切換時的工作連續性，以及各寬度下四邊安全區與短視窗浮層可達性。

## Impact

- 前端預計涉及app.scss、styles.scss、角色shell／表單容器、冒險／物品表單及裁切對話框；優先CSS調整，僅在實際可視區與layout viewport不同時考慮最小事件處理。
- 使用既有Angular Material、Signals與CSS環境變數；不新增套件、後端API或資料庫migration。
- 不改資源計算、既有快取／登入／更新規則；不承諾頁面重載後草稿復原或全面Duo實機相容。
- 官方來源及原生／網頁差異見design.md。
