# Proposal

## Why

1.3.0 已改善手機密度與篩選，但以 material-design-3-ui 盤點目前原始碼，仍有讀取失敗誤呈空資料、分頁與內容關聯、裁切鍵盤操作及表單錯誤復原缺口。1.4.0 將優先補足語意、狀態與無障礙，再整理設計 token，讓既有雙主題與跑團紀錄工作流程更一致。

## What Changes

- P1：列表提供持續可見的載入失敗與重試；詳情區分不存在與暫時性讀取錯誤；編輯物品在成功載入前禁止儲存。
- P1：角色路由導覽與倉庫同頁分頁，各自與實際內容建立正確語意及鍵盤關聯。
- P1：頭像裁切提供具名稱的縮放控制及鍵盤位移；表單驗證提供可定位錯誤、保留輸入與可感知的提交狀態。
- P1：刪除確認在 M3 主題下明確使用破壞性語意，保留取消初始焦點；非刪除確認不共用刪除強調。
- P2：補齊 Material surface／on-surface／error 角色對應、字體與容器角色；保留淺色藍、深色紫與 D&D 資源識別色，移除不必要的元件內部覆寫。
- P2：完成跨頁、雙主題、斷點、大字、鍵盤與輔助技術驗收；寬視窗及容器精簡先以具體方案比較，未確認前不重排桌機核心流程。
- 盤點、證據與優先次序見 [audit.md](audit.md)。本次只建立改善規劃，不改產品版號，不代表已完成 1.4.0 或已授權發布。

## Capabilities

### New Capabilities

無。

### Modified Capabilities

- `mobile-pwa`：新增跨裝置 UI 的可復原讀取狀態、分頁內容關聯、鍵盤裁切、表單復原、M3 確認操作及語意設計角色要求。

## Impact

- 前端：styles.scss、app、角色 shell／列表／表單／頭像裁切、冒險列表／詳情／表單、倉庫列表／表單、驗證頁與共用確認視窗。
- 文件：DESIGN.md、SRS 與 mobile-pwa 主規格在實作驗收後同步；本 change 先保存 delta。
- 沿用 Angular Material、原生 HTML 與現有 signals，不預設增加套件；API、資料庫及計算業務規則沒有預期變更。
- 保留 1.2.1／1.3.0 已驗收的手機字級、44px 操作範圍、資源收合與明細展開規則；寬視窗改版另經具體方案確認。

## 驗收範圍修訂

2026-10-09使用者在了解螢幕閱讀器驗收用途後，明確要求「跳過」。本版略過螢幕閱讀器的人工朗讀實測，保留已實作的語意、焦點、鍵盤操作與必要播報；不修改功能規格，也不把未執行的朗讀驗收標成通過。手機及真正瀏覽器200%縮放已有使用者驗收確認，寬版選配決策仍待回覆。
