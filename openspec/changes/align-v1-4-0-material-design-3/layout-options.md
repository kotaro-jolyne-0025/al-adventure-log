# 寬視窗與容器選配

[可操作同資料原型](../../../output/playwright/m3-layout-options.html)。所有資料為虛構。正式版截圖見 output/playwright/m3-light-characters-c-inventory-1280.png。

| 任務 | 現況 A：單頁＋卡片 | 候選 B：列表＋參考區／清單 |
|---|---|---|
| 閱讀一件物品後編輯 | 直接進入完整表單，流程短 | 參考區能先看來源，編輯仍進完整表單 |
| 比較兩件物品來源 | 進入第一件、返回、再進入第二件 | 依序選兩件，列表與所在位置持續可見 |
| 掃描名稱、稀有度與數量 | 卡片可換行、獨立操作清楚 | 清單以共同欄位對齊，適合較多物品；長中文名稱仍需增高 |
| 手機與大字 | 沿用已驗收收合與卡片 | 小視窗仍回單頁，不能把兩欄擠入手機 |

以上為流程分析，未量測完成時間或誤操作率。B 需增加選取物品狀態、直接網址／返回及無障礙焦點規格；實作前更新 change。卡片適合目前編輯導向的小型倉庫；先保留現況是保守建議。若經常進行多筆比較或掃描大量物品，可採用 B 或僅採清單。

決策：2026-10-09使用者明確回覆「先保留」，1.4.0維持A與既有倉庫卡片，不採用候選參考區或連續清單。後續摺疊手機驗證另行討論，不代表本版新增雙欄布局。
