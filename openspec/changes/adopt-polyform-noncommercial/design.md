# Design

## Context

現有 LICENSE 為 CC BY-NC-SA 4.0，網站免費服務宣告沒有明示程式碼授權。使用者已明確選擇 PolyForm Noncommercial 並授權部署，README 暫留本機。

## Decisions

- 使用官方 1.0.0 原文，不修改條款；另以 NOTICE 描述原創程式碼適用範圍、作者 Required Notice 及第三方權利。
- 前端 public/licenses 提供相同授權原文，公開法律頁與既有註冊彈窗使用相同摘要並連結原文；維持五節排版及原同好政策。
- 非商業摘要不宣稱一切收費均被禁止；說明特定慈善、教育、政府等機構用途依完整條款允許。
- 既有 CC 發布版本授權不被撤回；新版本的原創程式碼從 v2.0.0 改採 PolyForm。第三方套件、官方資料、商標與玩家內容不隨之重新授權。

## Risks / Trade-offs

這是公開原始碼、限制商用的軟體授權，不稱為標準開源。保留第三方套件與同好內容規範，授權改動不賦予威世智內容權利。

## Rollout

授權檔及前端聲明與本輪功能修正一併進入 PR、CI/CD 部署，README 修改保留本機。確認正式法律頁與部署 SHA 後交付手機驗收。
