- 同登入續期及跨分頁較新 Token 不取消個人資料請求或清除快取，不延後每日確認。較舊 Token 不能縮短期限。
- 登出／同帳號重新登入取消舊續期；另一分頁先寫入新登入而 storage 事件尚未到達時，舊續期或 401 不覆蓋／刪除新登入。續期後同登入舊請求的 401 仍會使目前登入失效。
- OpenSpec change strict validation、14 個主規格驗證及 `git diff --check` 通過；同步 identity-access 與 SRS。

- 提交前將僅含登入修正的 Git 暫存內容匯出至隔離副本重新驗證：後端 25 組／174 項、前端 36 組／236 項測試全部通過；前端正式建置及兩份 change strict validation 通過。未納入冒險匯出功能或其依賴。

## 限制

登入期限以最近成功續期起算，十分鐘節流使最後操作至到期時間最多相差十分鐘；純離線或已過期時需重新登入。持有有效 Token 者也能要求續期，密碼重設及停用仍可阻止後續續期。
