# Design

## Context

「取得來源」是最多 255 字的自由文字。既有來源冒險關聯參與戰利品同步及刪除，不能用於純文字捷徑。

## Goals / Non-Goals

新增與編輯表單可選同角色冒險並帶入來源文字。API、資料庫與既有戰利品關聯不變。

## Decisions

使用 Material 自動完成元件，讓來源文字輸入與欄內下拉清單共用一個欄位；沿用現有冒險讀取服務，首次開啟才載入。只列出非空白的冒險名稱；同名合併成一個選項，依同名最近遊玩日期由新到舊排列。選擇後以文字取代欄位內容並收合清單，同一名稱可以再選。手打不強制選擇，也不隱藏清單中的其他冒險。清單獨立處理載入、空白和失敗，失敗可重試；任何狀態都可手動填寫及儲存。

## Risks / Trade-offs

冒險名稱與來源欄位的上限均為 255 字，選取時不附加代碼或日期。既有自由文字不回填成關聯，不寫入任何冒險或快照 ID。
